# 知行研学

面向中小学生、大学生、职业教育、党校干部、企事业单位与普通成年人的研学课程和活动设计应用。

## 在线使用

- 生产网址：https://zhixing-study-3831353544.netlify.app/index.html?v=179-blue24
- 原二维码继续有效：assets/qr/zhixing-production-url.png

## 核心能力

- 根据关键字、目的地、适用人群、时长、人数和预算生成研学方案
- 覆盖中小学生、大学生、职业教育、教师、亲子家庭、成人、银龄、企业与党校干部
- 覆盖红色教育、历史文化、非遗传承、自然生态、科技创新、劳动实践、工业研学、乡村振兴、法治教育与国防教育
- 输出课程目标、分时日程、活动设计、成果任务、安全提示、物资与预算建议

## 下载与运行

在 Releases 下载 ZIP。Windows 解压后双击 `start-windows.cmd`；macOS/Linux 执行 `node server.mjs`。需要 Node.js 22 或更高版本。

本地下载版可以浏览应用并使用课程方案设计器的本地生成能力。账号、数据库、在线 AI、地图、邮件等完整在线能力需要配置 Netlify 环境。
